# BAGULAS

ゲームボーイ(DMG)風の縦スクロール・レース&シューティング。
荒野をバギーで疾走し、編隊を組む敵と濃いライバルレーサーを撃ち抜く。

**遊ぶ**: https://sonohoka.sakura.ne.jp/bagulas/

## これは何か

将来の実機ROM(GBDK-2020)移植を前提に、DMGの制約を厳密に守って書かれたWebゲーム。

- 160×144 / 4階調固定
- 全座標・速度は 8.8 固定小数点の整数演算(float 禁止)
- 三角関数を使わない(狙い撃ちは16方向テーブル + 象限判定)
- スプライト相当は画面内40 / 横一列10。超過時は実機同様にちらつかせる
- 乱数は 8bit LFSR
- 60fps 固定タイムステップ(catch-up 上限1。過負荷時はゲーム全体が一緒にスローになる)

この制約下で書かれているので、ロジックはそのままC(GBDK)へ移しやすい。

## 動かす

ビルド不要。素の ES modules なので静的配信するだけで動く。

```
python3 -m http.server
# → http://localhost:8000/
```

## 構成

| パス | 内容 |
|---|---|
| `src/` | ゲーム本体(素の ES modules) |
| `src/raster-canvas.js` / `raster-fb.js` | 描画バックエンド2種。Canvas 直描きと、160×144のフレームバッファ書き込み |
| `art/generated/` | スプライトデータ(4階調に量子化済み) |
| `art/prompts/` | 生成に使ったプロンプト(再現用) |
| `docs/spec.md` | 仕様 |
| `docs/enemies.md` | 敵キャラ設計 |
| `tools/` | アート生成・変換スクリプト |

## 描画バックエンドについて

同じゲームロジックが2つの出力先で動く。

1. **Canvas**: 単体Web版。上記の静的配信で動くのはこちら
2. **フレームバッファ**: `Uint16Array(160*144)` に shade 0..3 を書き込む。
   ゲームボーイエミュレータ [brickboy](https://github.com/kathoc/brickboy) の
   ソフトカート機構に載せて動かすためのもの(エミュレータ側の実機風LCD表示と
   タッチ十字キーをそのまま使える)

2は brickboy 側のリポジトリと組み合わせて使う。本リポジトリはゲーム部分のみを含む。

## 操作

| 入力 | 動作 |
|---|---|
| 十字キー / WASD | 移動 |
| Z / J | ショット(画面内2発まで。押しっぱなしで秒間12発) |
| X / K | 武器切替 |
| Enter | スタート |

## クレジット

グラフィックは [SpriteLab](https://spritelab.dev) で生成し、4階調へ量子化している。
フォントは同作者の gbtetrin から移植した縁付き4×8ドットフォント。
