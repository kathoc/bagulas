# BAGULAS 敵キャラ設定 v2(実装前の設計)

グラディウス(横スクロール → 縦に回転)とゼビウスを下敷きに、16種を設計する。
実装はまだ行わない。数値は目安であり、実装時に体感で詰める。

## 設計の軸

**敵は全て「走者」とする。** 路面に固定されてスクロールと一緒に流れてくる地物型の敵は作らない。

- 路面上の障害物は**敵ではない**。倒す対象でも点数源でもなく、接触しても死なない
  (引っ掛かって0.5秒動けなくなるだけ。射撃は可能)。コースの形の一部として扱う
- したがって敵は全て**撃つ対象**であり、プレイヤーの意識は「狙う」に一本化される
- 避ける対象は「敵弾」と「敵本体」だけ。濃度4が見えたら死ぬ、で常に正しい

ゼビウスの対空/対地のうち**対空だけを採る**、と言い換えてもよい。
そのぶん、走者の中で「撃ってくる/来ない」「速い/遅い」「壊せる/壊せない」の差を作る。

グラディウスの横方向パターンは90度回して使う。
「奥から来て引き返す」「跳ねる」「並走する」が縦画面での対応物になる。

## 出現の単位(ウェーブ)

敵は**ウェーブ単位**で出す。1体ずつだらだら湧かせない。

### 1ウェーブの決まり

- **1種類の敵のみ**で構成する。混成にしない
- **3〜5機**の編成
- **出現口は1か所だけ**。ウェーブの全機が同じ場所から出る
- 出しきったら次のウェーブまで**空き時間**を置く
  - 目安 **90〜150フレーム(1.5〜2.5秒)**。ステージ後半・周回で短くして難度を上げる
  - 空きの間は敵が居ない。片付けと位置取り直しの時間になる

### ウェーブの並べ方

同じ種類を**出現口を変えて数ウェーブ続け**、そのあと別の種類へ切り替える。

```
ドリフター 4機 ← 左前  → 空き → ドリフター 4機 ← 右前  → 空き
→ ドリフター 3機 ← 正面 → 空き → (種類切替) チェイサー 3機 ← 右後 → …
```

同種を繰り返すことで**その敵の動きを学習させ**、出現口を変えることで**同じ対処が通じない**ようにする。
種類の切り替えが節目になり、道中に段落ができる。

### 出現口(5か所)

| 記号 | 位置 | 説明 |
|---|---|---|
| **前左** | 画面上端の左寄り | 前方から来る。左へ寄って登場 |
| **前右** | 画面上端の右寄り | 同上、右寄り |
| **正面** | 画面上端の中央 | 真正面から来る |
| **後左** | 画面下端の左寄り | 背後から追い上げてくる |
| **後右** | 画面下端の右寄り | 同上 |

- 敵の種類ごとに**使える出現口が決まっている**。正面からしか出ない敵がいてよい
- **背後タイプは原則プレイヤーが居ない側から出す**。真下から重なって湧かせない
  (自機が右寄りなら後左、左寄りなら後右)
- 背後から出た敵は画面外への抜け先が上になるため、**追い越していく**動きになる

### 例外

- 大型(ハーベスタ)は**単体で1ウェーブ**扱い。出現中は他の湧きを止める
- サンドワームは砂中を潜行して任意の位置に浮上するため、出現口の概念を持たない
- ランスは画面の左右端から水平に突進する専用の出方をする

この単位はスプライト上限にも効く。16×16は1体4枚なので、5機で20枚。
自弾・敵弾・煙・エフェクトを足しても40枚に収まる。

## 雑魚敵は一撃離脱

雑魚敵は画面に居座らない。**入ってきて、1回仕掛けて、抜けていく。**

- 攻撃を持つ種は**原則1回だけ撃って離脱**する。同じ個体が何度も撃たない
- 攻撃を持たない種は、そのまま横切って抜ける
- **一度完全に画面外へ出た敵は復活しない**。戻ってこないし、再利用もしない
  - ただし**ボスは除く**(画面外へ退いてから戻る演出を許す)
  - 実装上の注意: 敵は画面外(上または下)からスポーンするので、
    「まだ一度も画面内に入っていない個体」を画面外判定で消してはいけない。
    **一度画面内に入ったことがある個体が完全に出たら消す**、が正しい判定
- 結果として、画面上の敵は常に入れ替わり続ける。滞留しないのでスプライト枠も空く

### 例外(居座る性格の種)

以下は設計上「そこに構えている」ことが性格なので、一撃離脱の対象外とする。

- **ガンワゴン**: 画面上部に居座って撃つ。ただし**撃つのは2〜3回まで**とし、そのあと離脱する
- **ハーベスタ**: 大型。波状攻撃が持ち味なので居座る
- **マザー**: 雑魚を射出し続ける役なので、一定回数射出してから離脱する

## 動きは「振り付け」で定義する

**複雑さより、読めることを優先する。**
敵の動きは、傾向(蛇行する・横へ流れる)ではなく、**時間で区切られたフェーズ列**として定義する。
プレイヤーが「次にどう動くか」を予測できることが、避ける・狙うの前提になる。

各フェーズは **持続時間(フレーム)** と **その間の動き** を持つ。フェーズ列は種ごとに固定。

### 振り付けは「1体ごと」に踏ませる

**編隊をひとかたまりとして動かさない。** 同じフェーズ列を、**1体ずつ時間差で**踏ませる。

- 各機は自分の時計を持つ。開始が **数フレームずつ遅れる**(目安 8〜14フレーム)
- したがって、静止するタイミングも発射するタイミングも機ごとにずれる
- 停止位置も機ごとに違う(進行方向に沿ってずれて並ぶ)

狙いは「フォーメーションをきっちり見せること」ではない。
**1体ずつバラバラに動いているのに、出現位置とタイミングのずれによって流れるように見える**状態を作る。

弾も1体ずつ順に飛んでくるので、同時発射の壁にならず、避ける余地が生まれる。

### 基準となる形(ドリフター)

以下を全種の書き方の基準とする。

| # | フェーズ | 時間 | 動き |
|---|---|---|---|
| 1 | 進入 | **1.0秒(60f)** | 左上または右上から、編隊を組んで**画面中央あたりまで**到達する |
| 2 | 静止 | **0.5秒(30f)** | その場に留まる(予備動作) |
| 3 | 発射 | — | 自機へ向けて**1撃** |
| 4 | 静止 | **0.5秒(30f)** | その場に留まる |
| 5 | 離脱 | — | **登場した方向とは逆の斜め上**へ、**V字を描いて**戻っていく |

読みどころは「中央で止まる0.5秒」。ここが撃ち込みどころであり、同時に発射の警告でもある。
止まる → 撃つ → 止まる → 帰る、という4拍のリズムを作る。

### 守ること

- **フェーズの境目が見て分かること**。特に「静止」は完全に止める(遅くするのではなく止める)
- **同じ種は毎回同じ順序・同じ時間**で動く。乱数で揺らすのは出現位置と離脱の左右だけ
- 「まっすぐ下へ降りるだけ」は作らない。ただし**複雑にするためではなく、リズムを作るために動かす**

### 進入(画面に入るまで)

| 名前 | 動き |
|---|---|
| 直下 | まっすぐ入る |
| 斜行 | 斜めに入る(横成分を持って入場) |
| 弧入 | 弧を描いて入り、進行方向が変わる |
| 横入 | 画面の左右から水平に入る(ランス) |

### 巡航(画面内での主たる動き)

| 名前 | 動き |
|---|---|
| 蛇行 | 左右に大きく往復しながら降りる |
| 滑走 | 画面幅を大きく横断する |
| 跳躍 | 跳ねながら降りる(ホッパー) |
| 追従 | 自機の位置に応じて動く(ミラージュ/チェイサー) |
| 停留 | その場に留まる(ガンワゴン/ハーベスタ) |

### 離脱(一撃後の去り方) — ここを特に作り分ける

| 名前 | 動き |
|---|---|
| **横流れ** | 左右どちらかへ加速しながら流れ、**画面のサイドへ消える** |
| **八の字** | 左右へ振れながら降り、交差する軌跡を描いて抜ける |
| **反転上昇** | 斜め上へ切り返して戻っていく(来た方向へ帰る) |
| **弧離脱** | 弧を描いて反対側の端へ抜ける |
| 直下 | そのまま下へ抜ける(**多用しない**) |

- **画面のサイドへ消える敵がいてよい**。下へ抜けるだけにしない
- 離脱方向は個体ごとにばらす(同じウェーブの全機が同じ方向へ抜けると単調)

## 共通ルール(全16種が守る)

- 16×16スプライト(ハーベスタのみ大型)。判定は中心基準で見た目より小さく取る
- 縦速度はスクロールの1/2以下。**横に大きく動く**のが基本
- 発射前に必ず **減速 → フラッシュ → 発射**。減速ははっきり長く(縦横とも約1/5まで落とす)
- 自機が中心距離±32px以内にいる間は撃たない(帯の外で待機し、離れたら改めて予備動作を踏む)
- 濃度4を持つ = 当たると死ぬ

## A. 編隊で流れる雑魚(1〜4)

道中の基本。単体では弱く、編隊の形が主張になる。

### 1. スキャッター
- **元ネタ**: ゼビウスのトーロイド / グラディウスのファン
- **見た目**: 車輪だけの単車。回転する円盤に見える
- **移動**: V字編隊で降り、中央から左右へ広がる
- **攻撃**: なし。体当たりのみ
- **役割**: 教育用。撃てば消える/当たれば死ぬ、を最初に教える

### 2. ドリフター
- **元ネタ**: グラディウスのザブ
- **見た目**: 低く構えたバギー。後輪が大きい
- **移動**: 縦列で降り、画面中程から左右へ大きく蛇行
- **攻撃**: 蛇行の折り返し点で1発だけ狙い撃ち
- **役割**: 「横に大きく動く」の主役。横切る敵に当てる練習

### 3. リーパー
- **元ネタ**: グラディウスの赤い編隊(全滅ボーナス)
- **見た目**: 同じ車体が5台。1台だけ旗を立てている
- **移動**: 斜めに流れて画面外へ抜ける。滞在が短い
- **攻撃**: なし
- **役割**: **抜けきる前に5台倒すと高得点**。自弾2発制限下での速射の腕試し

### 4. ホッパー
- **元ネタ**: グラディウスのジャンパー
- **見た目**: 脚の生えた四輪。関節がむき出し
- **移動**: 跳ねながら降下。着地の瞬間だけ停止
- **攻撃**: 着地の硬直中に真下へ1発
- **役割**: 硬直=撃ち込みどころ。リズムで倒す

## B. 撃ってくる中堅(5〜8)

弾を持つ。予備動作の見せ方がそれぞれ違う。

### 5. ガンワゴン
- **元ネタ**: グラディウスの砲台を空中化 / ゼビウスのテラジ
- **見た目**: 砲を積んだ装甲車。砲身が長い
- **移動**: **画面上部に居座り、左右へ滑る**。降りてこない
- **攻撃**: 16方向の狙い撃ち
- **役割**: 定点から撃ってくる圧。地物を廃したぶんの役割を引き受ける。
  **砲身の向きが予備動作そのもの**になるので、テレグラフの基準として使う

### 6. サンドワーム
- **元ネタ**: ゼビウスのソル(隠れているもの)
- **見た目**: 砂を割って出る蛇腹。潜行中は砂煙だけが動く
- **移動**: 砂中を潜行して自機へ寄り、任意の位置で浮上する
- **攻撃**: 浮上後に放射状3発
- **役割**: 潜行中は**無敵かつ判定なし**。どこから出るかを読む敵。
  砂煙の盛り上がりが唯一の警告

### 7. サイドカー
- **見た目**: 二人乗り。後席が荷物を抱えている
- **移動**: 左右に大きく往復しながらゆっくり降下
- **攻撃**: 山なりの投擲。自機の**現在地ではなく移動先**を狙う
- **役割**: 止まっていると当たる。動き続けさせる敵

### 8. ミラージュ
- **見た目**: 自機とよく似たシルエットのバギー
- **移動**: 自機の左右の動きを**反転して真似る**
- **攻撃**: 一定間隔で現在地へ1発
- **役割**: 動くほど正面に来る。止まると当てられる。ジレンマを作る

---

## C. 絡む単騎(9〜12)

1〜2体で出て長く付き合う。ライバル戦の予兆。

### 9. チェイサー
- **元ネタ**: ゼビウスのジアラ
- **見た目**: 前傾したバイク。ライダーが身を伏せている
- **移動**: 回り込んで**自機の真横に並走**しようとする
- **攻撃**: 並走が成立してから横撃ち
- **役割**: 並走を許すと撃たれる。位置取りを崩しに来る

### 10. ランナー
- **元ネタ**: グラディウスのファン(来て引き返す)
- **見た目**: 荷台に何か積んだトラック
- **移動**: 降下 → 中程で停止 → 引き返す
- **攻撃**: 反転直前に後方(自機側)へ2発
- **役割**: 深追いを罰する

### 11. ボマー
- **元ネタ**: ゼビウスのガルデロタ
- **見た目**: 燃料タンクを抱えた小型機
- **移動**: 高速降下し、画面中程で**自壊する**
- **攻撃**: 自壊時に放射状の破片
- **役割**: **倒せば爆発しない**。撃つ判断そのものが攻略になる

### 12. モノリス
- **元ネタ**: グラディウスのモアイ(リング弾)
- **見た目**: 石像を積んだ低床トレーラー。石像の口が開く
- **移動**: 低速でまっすぐ降りてくる
- **攻撃**: **リング状に等間隔の弾**。開口が長い予備動作
- **役割**: 弾の隙間を抜ける快感。敵弾8発上限を1体で使い切るため単独で出す

---

## D. 大型・特殊(13〜16)

### 13. ホイールソー
- **元ネタ**: ゼビウスのバキュラ(破壊不能)
- **見た目**: 巨大な鋸輪。濃度4の塊
- **移動**: **左右の画面端で跳ね返りながら**降りてくる
- **攻撃**: なし。**破壊不能**
- **役割**: 「撃てないものがある」を教える。避ける腕だけを問う
- **注意**: 無敵は苛立ちに直結する。必ず抜けられる間隔で出し、複数同時には出さない

### 14. マザー
- **元ネタ**: グラディウスのハッチ(敵を出す)を走者化
- **見た目**: 後部ハッチのある大型トレーラー
- **移動**: ゆっくり降下しながら左右へ
- **攻撃**: ハッチからスキャッターを連続射出
- **役割**: 放置すると増える。優先度の判断を迫る

### 15. ランス
- **見た目**: 長い槍を構えた騎手
- **移動**: **画面の左右から水平に突進してくる**(縦画面では珍しい軌道)
- **攻撃**: なし。体当たり
- **予備動作**: 突進前に画面端で光る
- **役割**: 縦の動きに慣れた目を横から刺す

### 16. ハーベスタ
- **元ネタ**: ゼビウスのアンドアジェネシスを雑魚化
- **見た目**: 巨大な収穫機。画面幅の半分弱を占める
- **移動**: 極めてゆっくり降下
- **攻撃**: 複数の砲口が順番に予備動作 → 順に発射(波状)
- **役割**: 中ボス手前の壁。**弱点は1か所**で、そこ以外は硬い
- **注意**: 出現中は他の敵の湧きを抑える(スプライト上限)
