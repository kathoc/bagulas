# BAGULAS — 仕様 v1(確定)

DMG(初代ゲームボーイ)風の縦スクロール・レース&シューティング。
荒野をバギーで疾走し、編隊を組む敵と濃いライバルレーサーを撃ち抜く(ジョジョ7部風のなんでもあり世界観)。

## 実行ターゲット

- **Web(Canvas/JS)で作り込む。ただし将来の実機ROM(GBDK-2020/C)移植を前提に、DMG制約を厳密に守る**
- 配信先: さくらレンタルサーバ静的配信。**ビルド不要の素のJS(ES modules)+Canvas、フレームワーク・バンドラ禁止**

## 移植性ルール(全実装で強制)

1. 解像度 160×144、4階調(DMG緑系パレット)固定。Canvasは整数倍スケールで表示
2. 全座標・速度は **8.8固定小数点の整数演算**。float禁止(描画時の変換のみ可)
3. `Math.atan2`/三角関数禁止。狙い撃ちは **16方向テーブル+象限判定**
4. グラフィックは 8×8 タイル単位。スプライト相当は **画面内40 / 横一列(スキャンライン相当)10** をJS側でも守る。
   **超過時は実機GBと同じくちらつかせる**(詳細は「スプライト超過の扱い」)
5. 乱数は 8bit LFSR(シード再現可能)
6. ロジックは 60fps 固定ステップ(requestAnimationFrame + 固定タイムステップ)
7. サウンドはGB音源相当(矩形波2+波形1+ノイズ1)の範囲で設計(実装は後回し可)

## 操作

| 入力 | 動作 |
|---|---|
| 十字キー(←→↑↓ / WASD+Arrow) | バギー移動(左右+前後) |
| A(Z/J) | ショット。**自弾は画面内2発まで**(グラディウス式) |
| B(X/K) | 武器切替(3種サイクル) |
| Start(Enter) | ポーズ |

## 武器(最初から全所持、Bで切替)

自弾2発制限は全武器共通。性質だけ変える。

1. **リボルバー** — まっすぐ速い。基本武器
2. **鉄球** — 遅いが敵を貫通。軌道がわずかに湾曲(7部オマージュ)
3. **ダイナマイト** — 山なりに投げ、着弾点で小範囲爆発

## コアルール

- 縦スクロール。BG=荒野の道。**コース上に地形的な障害物**(岩・柵・轍・サボテン等)があり、接触でダメージ。障害物は避ける/一部は破壊できる
- キャラクターサイズは **16×16**(自機・敵とも。8×8スプライト4枚構成相当)
- 敵は編隊(V字/縦列/蛇行など横に広がりすぎないパターン)。出現は**コース進行距離ベースのテーブル駆動**
- 敵弾: 16方向の狙い撃ち+固定方向。**画面内上限8発**
- ステージ=レース区間。区間の締めに**ボス**(専用攻撃パターン)。
  レースは演出(順位表示・ゴール演出)で表現し、順位メカニクスは持たない
- **全6ステージの周回制**。ステージ6クリア後は1へ戻り、周回ごとに難度上昇(敵の耐久/弾速/密度)
- スコア、残機、ゲームオーバー、リスタート

## ステージ構成(全6面)

各ステージは2部構成:
1. **前哨戦**: グラディウスの空中戦のような、障害物のない開幕セクション(編隊戦に集中)
2. **本編**: そのステージ特有の障害物が特徴のセクション → ボス戦

| # | 舞台 | 障害物の例 |
|---|---|---|
| 1 | 荒野 | 岩・柵・サボテン |
| 2 | ジャングル | 倒木・巨大植物・沼 |
| 3 | オアシス | 水場・ヤシ・遺跡 |
| 4 | 火山 | 溶岩流・噴石・亀裂 |
| 5 | 海の上 | 桟橋・浮遺物(+**ボスラッシュ**) |
| 6 | 洞窟 | 鍾乳石・落石・狭路 |

## ボス(全6体)とストーリー

- ボスは全6体。ステージ1〜4はライバルレーサー(ジョジョ7部風の濃いキャラ、各専用パターン)
- **ステージ5はボスラッシュ**: ステージ1〜4のボスを再戦(強化版)した後、5体目の新ボス
- **ステージ6の最後は、脳がむき出しの禍々しいメカ**が最終ボス(=レース主催者の正体)
- ストーリー: ステージを進むごとに「このレースの主催者は何者か」の真相に少しずつ迫る。
  ステージ間の短い一枚絵+テキストで演出(M1では不要、骨組みだけ)

## 手触り(最重視)

被弾・破壊・攻撃の全てにフィードバックを付ける。ここの実装品質を最優先する。

**滑らかさと軽快さの両立が絶対条件。**

- 通常時は 60fps を厳守し、スクロール・自機移動・弾はすべて毎フレーム更新の滑らかな動きにする
- 入力遅延は最小に: ボタン押下はそのフレーム内に反映。自機移動に慣性・加速のもたつきを入れない(即応が正義)
- **敵が多い場面の処理落ちは許容する**。実機GBのように、オブジェクト過多時はゲームロジック自体が遅くなる(=弾も敵も一緒にスローになる)挙動でよい。フレームスキップで弾だけワープする挙動は禁止
- 演出(フラッシュ・爆発)のためにゲームを止めない。ヒットストップを入れる場合も1〜2フレームまで

**コースの形**

- **道幅は従来の2倍**。基本的に全面がオンロード
- オフロードは**左右にランダムに出現する領域**として配置する(細い道を走るのではなく、広い道のところどころに危険地帯がある形)

**路面とオフロード**

- 路面のスクロールは通常は等速
- 自機が路面から外れる(オフロード)と:
  - **スクロール自体が 2/3 に低下**(前に進めなくなる=レースとしてのペナルティ)
  - 移動速度が 2/3 に低下
  - 自機が上下に揺れる。**ガタつきは控えめ**(激しくしない)
  - 8×8の砂煙スプライトが自機の右下・左下に発生。**煙は下方向へ流れて消える**(点滅+下へ流れる)
- 敵も路面外では同じ挙動(揺れ+減速)。煙は不要
- 復帰したら即座に通常挙動へ戻る

**視認性(濃さ = 危険度の記号化)**

濃さで危険度が読めることを保証する。3段階。

| 濃度 | 意味 | 該当 |
|---|---|---|
| **4**(最暗) | **当たると死ぬ** | 敵、ボス、敵弾、自弾 |
| **3** | **引っ掛かる**(死なないが停止する) | 障害物 |
| **2以下** | 無害。**当たり判定を持たない** | 地面・道・路肩・轍などの装飾 |

「一番濃い塊が見えたら死ぬ」で常に正しい判断になる状態を保つ。

**スプライト超過の扱い(ちらつかせる)**

画面内40 / 横一列10 を超えたとき、**オブジェクトを完全に消してはいけない**。
実機GBの実装と同じく、描画順を毎フレーム回して**ちらつかせる**ことで存在を伝える。

- **消えてよいのは自弾だけ**。敵・敵弾・障害物は、ちらついてでも必ず表示する
- 優先順位(枠が足りないとき、下から捨てる):

  1. 自機
  2. **敵弾**(見えないと理不尽に死ぬ。最優先で残す)
  3. **敵**
  4. **障害物**
  5. 爆発・スコアポップ等のエフェクト
  6. 砂煙
  7. **自弾**(最後。消えても撃ち直せる)

- 同一優先度の中では、**毎フレーム開始位置をずらした巡回順**で描く。
  こうすると「毎フレーム同じ個体だけが消える」状態にならず、全個体が交互に表示される
  = ちらつきながらも全部見える
- 現状の「上限に達したら以降を描かない」「スポーンを抑制する」方式は廃止する

**障害物(敵ではない)**

障害物は**敵として扱わない**。倒す対象でも、点数源でもない。コースの形の一部。

- 接触してもダメージ・ミスにはならない。代わりに**引っ掛かって一瞬動けなくなる**
  - **移動のみ不可。射撃はできる**(手が完全に止まる時間を作らない)
  - 拘束時間の目安 **30フレーム(0.5秒)**
  - スクロールは止めない。**進行が損をする=レースとしての罰**であって、死ではない
  - 拘束中であることが見て分かること(自機を揺らす、砂煙を出す等)
- 破壊できる障害物は残してよいが、**倒す動機は「道を空ける」だけ**にする(スコアを与えない)

**敵は走者のみ**

路面に固定されてスクロールと一緒に流れてくる「地物」型の敵は作らない。
敵は全て路面と無関係に動く**走者**とする(詳細は `docs/enemies.md`)。

**フォント**

- 文字は **gbtetrin の縁付き 4×8 ドットフォント**を使う
  - 実体: `~/Playground/gbtetrin/src/gen/gfx_data.c` の `gfx_font[336]`(42字 × 8バイト。1バイトが4px幅のニブル行)
  - 文字集合と字形の対応は `~/Playground/gbtetrin/src/main.c` の `text_glyph()`
  - 縁取りは実行時にビット演算で8方向へ生成する(`glyph_pair()` の `text_decor == 1` の分岐)。
    データを持たず算出する方式をそのまま流用する

**HUD**

- スコア・残機などの表示は**1行に圧縮**する(4×8フォントなら横に詰められる)
- 空いた分だけ**ゲームの表示域を広げる**

**当たり判定**

方式は **AABB(軸並行矩形)**。円は使わない(固定小数点で距離計算をしたくない、かつ矩形のほうが挙動が読める)。

- **すべてのエンティティの判定を「中心点 + 半径(halfW, halfH)」で定義する**。左上基準の生の座標をそのまま判定に使わない
  - 左上基準はオフセットの足し忘れで静かにずれるため、判定APIは中心基準のみを受け付ける形にする
- **判定サイズは見た目より小さく取る**。スプライトの透明な余白を判定に含めない
- **自機は中央 8×8 のみ**(16×16スプライトの外周4pxには判定を持たない)
- 敵・障害物・ボス・弾も、スプライト矩形そのままではなく**実体の見た目に合わせた中心基準の矩形**を各々持つ
- 弾は特に小さく取る(自弾・敵弾とも、見た目の芯だけ)

**敵の挙動**

- **縦速度はスクロール速度の 1/2 以下**。ゆっくり降りてくる
- **左右に大きく動く**。横移動が敵の主たる動き
- 発射の予備動作を強化する: **減速 → フラッシュ → 発射** の順(見てから避けられることを保証)
  - **減速ははっきりと、長めに**。「あ、撃つな」と分かる時間を取る(短い一瞬では足りない)
  - 減速中であることが見て分かること(速度差が明確に出る量まで落とす)
- **自機が 32×32 の範囲内にいるときは撃たない**(至近距離での回避不能弾を作らない)
- 採用値: 敵縦速度は `96/256px/frame`、SNAKEは `±40px` / `128` step、V字は `16px` 間隔かつ最大 `32px` offset。発射40f前から縦速度を1/2にし、20f前からフラッシュする
- 採用判断: 近距離発射抑止は攻撃をキャンセルせず `atkTimer=1` で保持し、中心距離がx/yとも32px以内の間は弾をspawnしない。完全停止・攻撃キャンセル・新編隊・三角関数ベース移動は、操作感または固定小数点/既存構造の制約に対して利点が小さいため見送る

**自機死亡と復活**

- 被弾死亡時: 自機の爆発モーション再生 → **スクロールがゆっくり減速して停止**
- リスポーン時: **スクロールが徐々に加速して元の速度へ戻る**
- リスポーン後は自機が点滅して無敵状態を明示。**無敵時間は3秒(180フレーム)**
- (「路面スクロールは等速」の例外はこの死亡/復活の減速・加速のみ)

**連射**

- 発射ボタンは押しっぱなしで**秒間12発程度のオート連射**(5フレーム間隔)
- 画面内2発制限は維持(空きがなければ発射せず、次の空きで撃つ)

- **敵にダメージ**: 1〜2フレームの白フラッシュ+ヒットSE(実装前でも視覚だけ先行)
- **敵を破壊**: 爆発アニメ(2〜3パターン)+小さな破片スプライト+スコアポップ
- **敵の発射予備動作**: 弾を撃つ前に必ず数フレームの予備アクション(点滅・構え・膨らみ等)を入れ、「見てから避けられる」を保証する
- 自機被弾: 無敵時間+点滅+短いノックバック
- DMGで再現可能な範囲に限る(半透明・パーティクル大量は禁止。スプライト差し替えとパレット反転で表現)

## グラフィック制作(SpriteLab)

- キャラクター・障害物・背景素材は **SpriteLab API** で生成する
  - エンドポイント: `POST https://spritelab.dev/api/v1/backgrounds`(Bearer認証、キーは環境変数 `SPRITELAB_API_KEY`)
  - 参考クライアント: `~/Playground/with-labyrinth/tools/spritelab_gen.py`(パラメータ: prompt / style_notes / quality / width / height / pixel_scale / max_colours / detail / contrast / saturation。応答は `image_b64`)
  - 本プロジェクトにも `tools/spritelab_gen.py` として移植し、16×16(キャラ)・8×8/16×16(障害物)にダウンサンプル+4階調量子化するパイプラインを作る
  - 使ったプロンプトは `art/prompts/` に必ず保存(再現性)。生成のたびに画風が揺れないよう共通 style_notes を1本固定する
  - APIキーを引数・ログ・コードに書かない

## マイルストーン1(縦切り)

1区間を通しで遊べる形:
自機移動・スクロール・射撃・武器切替3種・雑魚編隊2〜3パターン・狙い弾・
ライバル中ボス1体・スコア・被弾/残機・ゲームオーバー→リスタート。
グラフィックは仮タイル(プログラム生成の矩形/簡易ドット)でよい。音は後回し。

## 変更記録: 2026-08-08 オフロード/視認性調整

目的:
- 弾を暗い路面や障害物上でも見分けやすくする。
- 細い蛇行道路ではなく、全幅オンロードを基準に左右のオフロード危険帯を配置する。
- オフロード時の速度低下、揺れ、煙を仕様どおり穏やかで読みやすい挙動にする。

採用仕様:
- 弾4種の index3 シルエットに、透明セルへ index0 の4近傍1pxアウトラインを起動時に付与する。
- 背景タイルID 0..6 は維持し、`buildMap()` は20列全幅をオンロード基準、左右最大5列のオフロード帯を6行以上継続する形にする。
- オフロード判定は行の左右エッジ走査を廃止し、該当ピクセル位置のタイルID分類で真偽値を返す。
- 障害物は常に安全オンロード帯 `40 <= x <= 104` に16px幅が収まるよう clamp する。
- スクロール速度は死亡/復活 ramp とオフロード係数 0x00ab を `fmul` で合成する。敵速度比は ramp のみを使う。
- 揺れは1px振幅のまま8フレームごとに反転する。
- 自機オフロード煙は固定長 `SMOKE` プールで生成・更新・点滅描画し、敵には発生させない。
- 障害物生成アートは index3 を許可する。

見送り案:
- `getRoadEdgesAtRow()` の互換維持: 古いエッジ走査 API を残すと判定基準が二重化するため廃止。
- スクロール速度 ramp 自体へオフロード係数を焼き込む案: 死亡/復活の正規状態と路面ペナルティが混ざるため不採用。
- 煙の動的配列/オブジェクト生成: 毎フレーム割り当て禁止に反するため不採用。

完了条件:
- 指定 grep で旧道路 API が残っていない。
- `src/*.js` の固定小数点/乱数/割り当て制約を満たす。
- 障害物アートに index3 が含まれ、16x16 生成物が維持される。
- ヘッドレス起動でタイトルからPLAYへ遷移し、通常スクロール速度が256として観測できる。
